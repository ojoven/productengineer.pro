# Skill bodies

One MDX file per skill, named after the skill id: `mvp.mdx` is the body of
`/skills-map/strategy/product-scoping/mvp/`. The skill page shows it under the short description.
Files that start with `_` are ignored.

Bodies use figures by name, with no import, as In practice entries do (`docs/figures.md`). A link to
an In practice entry (`/in-practice/<id>/`) shows the entry's logo and avatar in front of it.

Format, rules and the batch plan: `docs/skill-bodies.md` and `docs/skill-bodies-batches.md`.
